VANGUARD1 — UI direction study

Same three panels, same real content, three design directions. Static mockup — nothing is wired up. Pick one (or parts of several) before any change lands in index.html.

Governing rule: the map is the content, the chrome is the frame. Chrome trends monochrome; colour is reserved for meaning. In every panel below, the only saturated element is the one thing that's actually wrong.
1 · Chart
Admiralty / NOAA chart heritage. Bone-white chrome on deep navy, brass accents, magenta for cautionary areas — an actual maritime convention, not a movie one. Hairline rules, no blur, no glow.

What to look for when you compare:

  • Find the problem. In each column, how fast does your eye land on the AIS gap? That's the entire argument for taking colour away from chrome. In the current UI that row would be cyan like everything else.
  • Squint. At a squint the panels should read as grey blocks with one coloured mark. If a border or a header glows through the squint, it's overweighted.
  • Density. Column 2 fits noticeably more per pixel. That matters when you have 15 panels on screen; it costs you the ability to breathe.
  • Distinctiveness. Column 1 is the one nobody else has — dark-mode chart conventions are genuinely rare. Column 3 is the safest and also the most familiar, which cuts both ways given the original complaint.

Mixing is legitimate: e.g. Chart's palette with Instrument's density, or Recessive's hierarchy with Chart's magenta. Fonts here are system stacks (Segoe UI / Cascadia Mono on Windows) so the mockup has zero dependencies — a real pick would ship a webfont.
