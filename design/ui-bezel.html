What this fixes beyond the skin:

  • The layout problem, not just the paint. A bezel is a CSS grid with four named regions. That replaces ~15 panels at hardcoded position:fixed offsets — the thing that actually makes the UI feel assembled rather than designed.
  • The map is never occluded. The center well is empty because your Three.js canvas fills it. Chrome sits in a frame around it, so a dive at camera.y < 15 is never fighting a floating card.
  • One accent, tiny areas. The last palette was muted colour over medium areas, which always reads dusty. This is neutral chrome plus a few square millimetres of vivid — live pips, the playhead, the speed bar, the anomaly bracket.
  • The bottom rail is your simClock. Scrub, rate, playhead, and event ticks — the reporting gap appears both in the vessel dock and as a bracket on the timeline, same colour, same event.
  • Left rail replaces the panel sprawl. Layers, search, measure, alert zones, zone record, camera, settings — all currently separate floating panels — become one 48px column with flyouts.

Fonts: switch with the buttons top-right. Pairing 3 uses JetBrains Mono as a stand-in for Berkeley Mono (paid, ~$75) — Berkeley is sharper but this shows the proportion. All others are free/OFL and load from Google Fonts; for production you'd self-host the woff2 files so the app works offline.
